  kenney-mini.ttf   <-  "Kenney Mini.ttf"
  kenney-pixel.ttf  <-  "Kenney Pixel.ttf"

Both are loaded as font assets (see src/asset.manifest.ts); UITheme's FONT preset
picks which one every textbox and menu label uses. AssetLoader registers each with
`new FontFace("<asset id>", ...)`, so the CSS family names are `kenney-mini` /
`kenney-pixel`.
